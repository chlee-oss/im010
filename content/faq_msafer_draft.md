## 1

**질문**
```
명의도용방지서비스(Msafer)가 무엇인가요?
```

**답변**
```
명의도용방지서비스(Msafer)는 내 명의로 통신서비스가 새로 가입되거나 명의변경(양수)될 때, 그 사실을 알려 주는 무료 공공서비스예요. 전기통신사업법 제32조의6에 근거해 한국정보통신진흥협회(KAIT)가 운영해요.

알림 외에도 Msafer 홈페이지(www.msafer.or.kr)에서 내 명의의 통신서비스 가입 현황을 조회하고, 다른 사람이 내 명의로 휴대폰을 개통하지 못하도록 미리 막아 둘 수 있어요.

출처: 한국정보통신진흥협회(KAIT) 명의도용방지서비스(Msafer) 서비스 소개 (https://msafer.or.kr/protection_use/guide.do)
```

## 2

**질문**
```
명의도용방지서비스는 따로 신청해야 하나요?
```

**답변**
```
가입사실 안내(문자 · 등기우편)는 법에 따라 제공되는 서비스라 따로 신청하지 않아도 돼요. 내 명의로 통신서비스가 새로 가입되거나 명의변경되면 자동으로 안내가 와요.

다만 아래 서비스는 Msafer 홈페이지(www.msafer.or.kr)에서 본인확인 후 직접 이용해야 해요.
- 가입제한 서비스 (휴대폰 개통 사전 차단)
- 가입사실 현황조회
- 이메일 안내서비스 (이메일 사전 등록 · 인증 필요)

※ Msafer 로그인은 공동인증서 또는 금융인증서로 본인확인을 해요. 인증서가 없을 때의 이용 방법은 Msafer 홈페이지 로그인 화면에서 안내하고 있어요.

출처: 한국정보통신진흥협회(KAIT) 명의도용방지서비스(Msafer) 서비스 소개 (https://msafer.or.kr/protection_use/guide.do)
```

## 3

**질문**
```
Msafer에서는 어떤 서비스를 이용할 수 있나요?
```

**답변**
```
Msafer의 주요 서비스는 다섯 가지예요.

1. 가입사실 문자(SMS) 안내
   내 명의로 새로 가입되거나 명의변경되면, 내 명의 휴대폰으로 계약 사실을 문자로 알려 드려요.

2. 가입사실 등기우편 안내
   내 명의 휴대폰으로 문자를 받을 수 없는 경우, 주민등록상 주소지로 등기우편을 보내 알려 드려요.

3. 가입사실 현황조회
   조회하는 날을 기준으로 내 명의로 개통된 통신서비스 회선을 한 번에 확인할 수 있어요.

4. 가입제한 서비스
   본인이 신청하면 내 명의로 휴대폰 개통(신규 · 번호이동 · 기기변경 · 명의변경)이 되지 않도록 미리 막아 둘 수 있어요.

5. 이메일 안내서비스
   미리 등록하고 인증한 이메일로 통신서비스 개통 사실을 안내받을 수 있어요.

안내 대상 통신서비스: 유선전화, 이동전화, 무선인터넷, 초고속인터넷, 인터넷전화, 방송서비스 (대리점 · 인터넷 가입 모두 포함)

출처: 한국정보통신진흥협회(KAIT) 명의도용방지서비스(Msafer) 서비스 소개 (https://msafer.or.kr/protection_use/guide.do)
```

## 4

**질문**
```
가입제한을 해 두면 휴대폰 개통이 안 되나요?
```

**답변**
```
네. 가입제한을 설정하면 내 명의로 휴대폰 신규가입 · 번호이동 · 기기변경 · 명의변경이 모두 막혀요. 알뜰폰 요금제로 개통하거나 번호이동할 때도 마찬가지예요.

개통을 하려면 먼저 Msafer 홈페이지(www.msafer.or.kr)에서 본인확인 후 가입제한을 해제해 주세요. 해제하면 개통할 수 있어요.

※ 가입제한 설정과 해제는 명의자 본인만 할 수 있어요. 알뜰폰사에서 대신 해제해 드릴 수 없어요.
※ 개통을 마친 뒤 명의도용이 걱정된다면 가입제한을 다시 설정해 두세요.

출처: 한국정보통신진흥협회(KAIT) 명의도용방지서비스(Msafer) 서비스 소개 (https://msafer.or.kr/protection_use/guide.do)
```

## 5

**질문**
```
내 명의로 개통된 회선을 확인하고 싶어요.
```

**답변**
```
Msafer 홈페이지(www.msafer.or.kr)의 [가입사실현황조회] 서비스에서 확인할 수 있어요. 본인확인을 하면 조회하는 날을 기준으로 내 명의로 개통된 통신서비스 회선을 한 번에 볼 수 있어요.

내가 모르는 회선이 있다면 명의도용일 수 있으니 바로 상담센터에 문의해 주세요.

출처: 한국정보통신진흥협회(KAIT) 명의도용방지서비스(Msafer) 서비스 소개 (https://msafer.or.kr/protection_use/guide.do)
```
